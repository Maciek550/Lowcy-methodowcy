# MatchThis – bieżące ustalenia

- Nowy projekt funkcjonalnie oparty na Łowcy Methodowcy, ale z całkowicie nowym UI inspirowanym matchthis.pl.
- Osobne wdrożenie na Railway.
- Sektory zawsze wzdłuż brzegu.
- Losowanie automatyczne z możliwością ręcznego wpisania / poprawienia stanowisk.
- Organizator prowadzi bazę zawodników i sam dodaje zawodników do zawodów.
- Role: ADMIN/ORGANIZATOR, SĘDZIA WAGOWY, USER/ZAWODNIK, GOŚĆ.
- USER/ZAWODNIK istnieje, ale konta są domyślnie nieaktywne; admin je włącza.
- GOŚĆ nie loguje się i ogląda publiczne, opublikowane wyniki oraz klasyfikację; losowanie tylko jeśli admin je opublikuje.
