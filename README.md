V107 — uproszczona lista zawodów

Nadchodzące: wszystkie bieżące i przyszłe, bez osobnej sekcji najbliższych trzech. Zapisane: aktywne zapisy i rezerwa. Historia: od następnego dnia po dacie zawodów, według czasu polskiego.
Formularz administratora domyślnie zwinięty pod „Robimy zawody”. Poprawiona czytelność Waga / Stan. / Sektor / BF. Przycisk „LOSOWANIE / WYNIKI” zachowuje rozmiar.
